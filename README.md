# 🌸 Onam Celebration Website

A festive and responsive Onam Celebration Website built using HTML, CSS, and JavaScript. The project showcases the beauty, traditions, culture, and celebrations of Onam in Kerala through an attractive and interactive web experience.

## 🌿 About the Project

Onam is one of the most important festivals celebrated in Kerala, known for its vibrant traditions, floral decorations, traditional food, cultural activities, and the spirit of togetherness.

This project is designed as a frontend web development project to combine web design, JavaScript interactivity, and Kerala's Onam culture into a single website.

## ✨ Features

🌸 Beautiful Onam-themed user interface
🪷 Responsive design for desktop, tablet, and mobile
🌼 Pookalam-themed visual elements
👑 Information about King Mahabali
🍛 Traditional Onam Sadya section
🥁 Onam traditions and cultural activities
🚣 Information about Vallam Kali (Snake Boat Race)
🎉 Onam celebration gallery
⏳ Interactive Onam countdown timer
🎵 Optional festive background music
📱 Mobile-friendly navigation
✨ JavaScript-based interactive elements

## 🛠️ Technologies Used

HTML5 – Website structure
CSS3 – Styling, animations, and responsive design
JavaScript – Interactivity and dynamic content
Bootstrap – Responsive layout and UI components (if used)
